## 📋 What Gets Extracted From Each Blog

The build script automatically extracts:
- **Title** - From `<title>` tag
- **Description** - From meta description tag
- **Keywords** - From meta keywords tag
- **Publication Date** - From post metadata
- **Tags** - From post tags section
- **Content** - From post content div (removes sidebars)

All automatically injected into templates → Optimized blog file
