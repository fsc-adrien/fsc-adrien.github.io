## 🐛 If Something Goes Wrong

### Build Script Fails
```
Solution:
1. Check Python version: python3 --version (need 3.6+)
2. Verify templates exist: ls templates/*.hbs
3. Try Node.js: npm install && npm run build
See: IMPLEMENTATION_GUIDE.md → Troubleshooting
```

### Blog Looks Broken
```
Solution:
1. Open F12 → Console (check for errors)
2. Open F12 → Network (check for 404s)
3. View page source to check meta tags
4. Compare with original blog file
See: IMPLEMENTATION_GUIDE.md → Troubleshooting
```

### SEO Tags Missing
```
Solution:
1. View page source (Ctrl+U / Cmd+U)
2. Search for "meta name" and "og:" and "twitter:"
3. If missing: templates may not be applied
4. Re-run build script
See: IMPLEMENTATION_GUIDE.md → Troubleshooting
```
